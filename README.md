# Coffee-Shop-Sales
# ☕ Coffee Sales Analysis — Power BI & SQL

This project analyzes coffee sales data using **SQL and Power BI** to uncover valuable insights into sales performance, customer purchasing patterns, product performance, and business trends.

## 📊 Project Overview

The objective of this project is to transform raw coffee sales data into meaningful business insights. SQL is used for **data cleaning, transformation, and analysis**, while Power BI is used to create an **interactive dashboard** for data visualization and reporting.

## 🛠️ Tools & Technologies

- **SQL** — Data cleaning, transformation, querying, and analysis
- **Power BI** — Interactive dashboards and data visualization
- **DAX** — Measures and calculated metrics
- **Excel/CSV** — Data source and initial data preparation

## 🔍 Key Analysis

The project focuses on:

- Total sales and revenue analysis
- Monthly and daily sales trends
- Best-selling coffee products
- Product category performance
- Sales by store/location
- Average order value
- Quantity sold and transaction analysis
- Peak sales periods
- Customer purchasing patterns

## 📈 Power BI Dashboard

The Power BI dashboard provides an interactive view of the coffee business, allowing users to explore sales performance through different KPIs, charts, filters, and slicers.

### Key KPIs

- 💰 Total Revenue
- 🛒 Total Transactions
- ☕ Total Quantity Sold
- 📦 Average Order Value
- 📈 Sales Growth

## 🗄️ SQL Analysis

SQL queries are used to extract and analyze important business information from the dataset, including sales trends, top-performing products, revenue by category, and time-based performance.

## 🎯 Project Goal

The main goal of this project is to demonstrate practical **SQL data analysis and Power BI dashboard development skills** by converting raw coffee sales data into actionable business insights.
